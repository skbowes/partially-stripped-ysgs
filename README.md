# Overview of files and workflow in 2022_asassn_lc_data (AKA, variability analysis of YSGs)

in practical order:

ASAS-SN lightcurve data in both g and V bands is stored in asassn_lc_data. Specifically, subdirectories:
    sub2025 (contains lightcurves for "final" stars AKA stars that made it past Anna's final cuts of having MCPS photometry AKA stars with indices < 848), 
    sub2026 (contains lightcurves for "prefinal" stars AKA stars that did NOT make it past Anna's final cuts AKA stars with indices > 848), and 
    ap_phot_avg (contains lightcurves for ALL stars that Ben Shappee ran for us in Sept 2026, through the new ASAS-SN pipeline for computing photometry).
